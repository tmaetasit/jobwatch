# jobwatch — แจ้งเตือนงานใหม่จาก 4 เว็บหางานเข้า Telegram

ตัวเช็คนี้รันบน GitHub Actions ทุก 15 นาที ตลอด 24 ชม. โดยไม่ต้องเปิดคอมทิ้งไว้ มันจะค้นงาน **Business Analyst** และ **Cyber Security** บน JobThai, JobsDB, JobBKK และ JobTopGun แล้วส่งงานที่ผ่านตัวกรองเข้า Telegram ทันที

| เงื่อนไข | ค่าที่ตั้งไว้ |
|---|---|
| คำค้น | Business Analyst, Cyber Security (ไม่สนตัวพิมพ์เล็ก-ใหญ่และช่องว่าง) |
| ตัดทิ้ง | ชื่อตำแหน่งที่มี Senior/Sr, Lead/Leader, Manager, Head, Director, Principal, ผู้จัดการ, หัวหน้า, อาวุโส |
| พื้นที่ | กรุงเทพฯ, สมุทรปราการ, งาน Remote/WFH (ติดป้าย 🏠) และงานที่ไม่ระบุพื้นที่ |
| กลางคืน | ช่วง 23:00–07:00 ข้อความเข้าทันทีแต่ไม่มีเสียง |
| เว็บพัง | ถ้าดึงข้อมูลไม่ได้ 3 รอบติดกัน จะได้ข้อความ ⚠️ และได้ ✅ อีกครั้งเมื่อกลับมาใช้ได้ |
| สรุปรายวัน | ส่งทุกวัน 09:00 บอกว่าเมื่อวานแต่ละเว็บเช็คสำเร็จกี่รอบ และแจ้งงานไปกี่ตำแหน่ง |

ทุกค่าในตารางแก้ได้ที่ไฟล์ `config.yaml` โดยไม่ต้องแตะโค้ด

---

## ตั้งค่า (ประมาณ 15 นาที ทำครั้งเดียว)

### 1) สร้าง Telegram bot
1. เปิด Telegram แล้วค้นหา **@BotFather** จากนั้นพิมพ์ `/newbot`
2. ตั้งชื่อบอทตามที่ BotFather ถาม แล้วจะได้ **token** หน้าตาประมาณ `123456789:AAH...` ให้เก็บไว้
3. เปิดแชทกับบอทที่เพิ่งสร้าง แล้วกด **Start** หรือพิมพ์อะไรก็ได้ 1 ข้อความ
4. เปิดลิงก์นี้ในเบราว์เซอร์ โดยแทน `<TOKEN>` ด้วย token ของคุณ:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   หาค่า `"chat":{"id": 123456789` ตัวเลขนี้คือ **chat id**

### 2) สร้าง GitHub repo
1. สมัครหรือเข้าสู่ระบบ https://github.com แล้วกด **New repository**
2. ตั้งชื่อ เช่น `jobwatch` แล้วเลือก **Public**
   > ทำไมต้อง Public: repo แบบ Public ใช้ GitHub Actions ได้ไม่จำกัด ส่วน Private ได้ฟรีแค่ 2,000 นาที/เดือน ซึ่งการรันทุก 15 นาทีใช้ประมาณ 2,900 นาที/เดือน
   > ใน repo จะเห็นแค่โค้ดกับรายการงานที่เคยเจอ ส่วน token และ chat id เก็บเป็น Secret ซึ่งไม่มีใครเห็น
3. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดจาก zip ลงไป ต้องมีโฟลเดอร์ `.github` ไปด้วย
   > ถ้าลากแล้วโฟลเดอร์ `.github` ไม่ขึ้น (มักเกิดบน Mac เพราะซ่อนไฟล์ที่ชื่อขึ้นต้นด้วยจุด) ให้กด **Add file → Create new file** แล้วพิมพ์ชื่อ `.github/workflows/jobwatch.yml` จากนั้นวางเนื้อหาจากไฟล์นั้นลงไป
4. กด **Commit changes**

### 3) ใส่ Secret
ไปที่ repo แล้วเข้า **Settings → Secrets and variables → Actions → New repository secret** สร้าง 2 ตัว:
- `TELEGRAM_BOT_TOKEN` = token จากข้อ 1
- `TELEGRAM_CHAT_ID` = chat id จากข้อ 1

แล้วเข้า **Settings → Actions → General → Workflow permissions** เลือก **Read and write permissions** แล้วกด Save (ตัวเช็คต้องใช้สิทธิ์นี้บันทึกรายการงานที่เห็นแล้ว)

### 4) รันครั้งแรก
1. ไปที่แท็บ **Actions** แล้วกดเปิดใช้งาน ถ้า GitHub ถาม
2. เลือก **jobwatch** จากนั้นกด **Run workflow**
3. รอประมาณ 1 นาที แล้วกดเข้าไปดู log ขั้น *Check job sites* ควรเห็นบรรทัดลักษณะนี้
   ```
   [JobThai] Business Analyst: เจอ 20 งาน, ใหม่ 20 (รอบแรก บันทึกเฉยๆ)
   ```
   **รอบแรกจะไม่ส่งแจ้งเตือนงาน** แค่บันทึกงานที่มีอยู่แล้วไว้ ไม่อย่างนั้นวันแรกจะมีข้อความเด้งเป็นร้อย หลังจากนั้นจะแจ้งเฉพาะงานที่ลงใหม่
4. ถ้าบรรทัดไหนขึ้นว่า `ล้มเหลว` ดูข้อ "ถ้าเว็บไหนใช้ไม่ได้" ด้านล่าง

จากนี้ระบบจะรันเองทุก ~15 นาที

## ข้อความที่จะได้รับ
```
🆕 Business Analyst
🏢 บริษัท ตัวอย่าง จำกัด
📍 เขตห้วยขวาง กรุงเทพมหานคร
💰 30,000 - 45,000 บาท
🌐 JobThai · เปิดประกาศ / สมัคร
```
ถ้างานเดียวกัน (บริษัทและตำแหน่งตรงกัน) ลงหลายเว็บ จะแจ้งแค่ครั้งเดียว

## ปรับแต่ง (`config.yaml`)
- **เพิ่มคำค้น:** ใส่เพิ่มใต้ `keywords:` เช่น `SOC Analyst`, `Information Security`, `นักวิเคราะห์ธุรกิจ` แต่ละเว็บจะเริ่มบันทึกคำใหม่เป็นรอบแรกก่อน แล้วค่อยแจ้งงานใหม่ตั้งแต่รอบถัดไป
- **ปล่อยงาน Senior มาด้วย:** ลบคำนั้นออกจาก `exclude_title_words`
- **ปิดบางเว็บ:** ตั้งค่าเป็น `false` ใต้ `sites:`

## ถ้าเว็บไหนใช้ไม่ได้
GitHub ดึงข้อมูลจากเครื่องในต่างประเทศ บางเว็บอาจบล็อกหรือขึ้นหน้ายืนยันว่าไม่ใช่บอท ถ้าได้ข้อความ ⚠️ ซ้ำๆ จากเว็บเดิม:
1. ปิดเว็บนั้นใน `config.yaml` (`false`) จะได้ไม่เตือนวนไปเรื่อยๆ
2. ตั้ง **Job Alert ของเว็บนั้นเอง** ไว้แทน (ใช้คำค้นและพื้นที่เดียวกัน)
3. หรือถ้าหน้าเว็บเปลี่ยนหน้าตา ต้องแก้ตัวแยกข้อมูลใน `sites.py` (ส่ง log มาให้ Claude ช่วยแก้ได้)

## ข้อควรรู้
- GitHub ไม่รับประกันเวลารันตามตารางเป๊ะๆ ช่วงที่คนใช้เยอะ บางรอบอาจช้า 5–15 นาที
- GitHub จะปิดตารางรันอัตโนมัติถ้า repo ไม่มีความเคลื่อนไหว 60 วัน ระบบนี้บันทึก `state.json` กลับเข้า repo ทุกวันจึงไม่ควรโดน แต่ถ้าเลิกได้รับสรุป 09:00 ให้เข้าแท็บ Actions แล้วกด Enable workflow
- เว็บส่วนใหญ่ไม่ได้อนุญาตให้ดึงข้อมูลอัตโนมัติในเงื่อนไขการใช้งาน ระบบนี้เช็คเบาๆ คือ 2 หน้าต่อเว็บ ทุก 15 นาที ไม่ควรตั้งให้ถี่กว่านี้
- ช่วงที่หางานได้แล้วอยากหยุด: เข้าแท็บ Actions → jobwatch → `…` → **Disable workflow**
